# Plan

Turn priorities into daily action and plans across time horizons.

## Subfolders
- `Daily/` for day-by-day priorities, activity, and outcomes
- `Todos/` for tasks and backlog items that need action
- `Goals/` for medium- and long-term outcomes
- `Weekly/` for weekly plans
- `Quarterly/` for quarterly plans
- `Reviews/` for review notes
- `Two-Year/` for longer-term direction

## Purpose
Keep daily execution aligned with bigger priorities.
