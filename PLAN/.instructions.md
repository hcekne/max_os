Plans across horizons. Daily execution stays aligned with longer-term
direction; ceremonies run when asked for or scheduled, never automatically at
session start.

## Layout and naming

- `Daily/` — one note per working day, `YYYY-MM-DD.md`
  (`SYSTEM/Templates/TPL - Daily.md`).
- `Todos/` — task backlog; see `Todos/.instructions.md`.
- `Goals/` — one note per major goal, `Goal - Name.md`
  (`TPL - Goal.md`); list active ones in `SYSTEM/State.md`.
- `Weekly/` — `YYYY-Www.md` (`TPL - Plan Weekly.md`).
- `Quarterly/` — `YYYY-Qn.md` (`TPL - Plan Quarterly.md`).
- `Reviews/` — review notes (`TPL - Review Weekly.md`).
- `Two-Year/` — longer-range direction (`TPL - Plan Two-Year.md`).

Keep one active note per horizon and record it in `SYSTEM/State.md` after a
review.

## Method

- **Daily**: pull due todos and active-goal work into today's note; top 1–3
  actions first.
- **Weekly** (~30–45 min, on request or scheduled): compare last week's plan
  with the daily notes — what was done, what slipped, why. Capture reusable
  lessons in `SYSTEM/Memory.md`. Draft the next weekly plan against the
  active quarterly plan, leaving buffer for unplanned work.
- **Quarterly** (~60–90 min): review outcomes vs the quarter plan, update
  priorities and constraints, refresh the next 12 weeks, check the two-year
  direction still holds.
- **Two-Year**: re-read the goal state; adjust trajectory when constraints
  or opportunities changed.

To run reviews on a cadence, schedule `Workflow - Planning Review` (or your
own automation) in the Workflow Builder — the workspace itself never demands
a ceremony.
