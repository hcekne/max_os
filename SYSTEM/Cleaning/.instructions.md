Central retention surface. Archive vs Rubbish Bin per retention value.

- `Archive/` - historically useful material, kept long-term.
- `Rubbish Bin/` - clearly stale, superseded, or low-value material; eligible for purge per `SYSTEM/Rubbish Bin Policy.md`.
- Always mirror the original source path beneath these roots so origin context stays obvious, for example `SYSTEM/Cleaning/Archive/KNOWLEDGE/Projects/Project Name/...`.
- Do not delete files outside the narrow rubbish-bin purge path defined in policy.
- Treat final deliverables, contracts, invoices, legal/commercial documents, and client-provided materials as high-retention. Default to `Archive/`, not `Rubbish Bin/`.
- See `SYSTEM/Archive Policy.md`, `SYSTEM/Rubbish Bin Policy.md`, `SYSTEM/Document Lifecycle Policy.md`, and `SYSTEM/Git Preservation Policy.md`.
