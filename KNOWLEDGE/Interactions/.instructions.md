One note per interaction (meeting, call, event). Use date-first filenames and
the template `SYSTEM/Templates/TPL - Interaction.md`.

After processing an interaction note:

1. Ensure every mentioned person has a note in `KNOWLEDGE/People/`.
2. Ensure referenced organization, client, and project notes exist.
3. Update relevant person notes with the latest interaction date, key facts,
   open loops, and links.
4. Update the referenced organization/client/project note with key updates
   and commitments.
5. Extract action items to `PLAN/Todos/` or today's daily note in
   `PLAN/Daily/`.
6. Return a short factual changelog of what was updated.
