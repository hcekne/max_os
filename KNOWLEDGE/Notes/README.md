# Notes

Use this folder for ideas and notes that do not belong in People, Clients, Projects, or Content yet.

Examples:
- random ideas
- research snippets
- thoughts you want to revisit
- rough drafts before they become structured notes

If a note becomes important, you can later move or link it into the right folder.

## Note lifecycle (important)
- Keep active/canonical notes in `KNOWLEDGE/Notes/` root.
- Move historically useful superseded or redundant notes to `SYSTEM/Cleaning/Archive/KNOWLEDGE/Notes/`.
- Move clearly stale low-retention notes to `SYSTEM/Cleaning/Rubbish Bin/KNOWLEDGE/Notes/`.
- Mark archived notes with `status: archived` in frontmatter.
- Prefer one canonical note per major strategy topic to reduce clutter for humans and AI.
- During monthly review, run quick note hygiene: consolidate duplicates, update links, and archive stale variants.
