# Projects

Store active project notes and track delivery.

## What to keep here
- project goal and scope
- owner and stakeholders
- current status
- next milestones
- open tasks and dependencies

## Personal vs Organization Projects
This folder is for the owner's personal project notes and supporting material.

In MaxOS Online, organization projects may be shared with the owner and added to
chat or workflow scope. Those projects are separate shared workspaces with their
own permissions. Do not silently copy their contents into `KNOWLEDGE/Projects/`; write
summaries or links here only when they become durable personal knowledge.
