# Skills

This folder contains agent-executable skill definitions — structured descriptions of tasks that AI agents can perform autonomously within Max OS.

## Use This Folder For
- capabilities an agent can execute autonomously
- tasks that benefit from a stable trigger, defined inputs, and explicit quality checks

## Guidance
- Use `SYSTEM/Templates/TPL - Skill.md` when creating a new skill.
- Keep the master manifest in `SKILLS.md` at the vault root.
- Use `AUTOMATE/Workflows/` for human-led processes instead of duplicating them here.
- Use the folder listing and `SKILLS.md` as the source of truth instead of maintaining a second catalog in this README.
