title: "How we'll run the FY27 transformation"
subtitle: "Four working principles — the room agrees to these before we start, not after we slip"
---

1. **Outcome first, not artefact.** Every workstream commits to a P&L outcome, not to a deliverable list.
2. **One owner per workstream.** Single named DRI; no co-leads, no committees, no shared accountability.
3. **Default to small.** If a decision needs four people, escalate. If it needs eight, redesign the decision.
4. **Decision speed beats decision optimality.** A signed-off 'B' on Friday beats an unsigned 'A' next Wednesday.
