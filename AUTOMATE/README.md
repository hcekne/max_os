# Automate

Reusable ways of working belong here.

- `Workflows/` — repeatable human-led processes and Workflow Builder automations.
- `Skills/` — reusable capabilities an agent can execute end to end.
- `Modules/` — optional capability packs that extend Max OS.

Keep durable knowledge in `KNOWLEDGE/` and plans in `PLAN/`; this area is for
reusable execution logic.
