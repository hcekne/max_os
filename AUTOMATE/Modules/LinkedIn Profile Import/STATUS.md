status: backlog
owner:
last_updated: 2026-08-07

## Purpose
Turn LinkedIn profile PDF exports into structured person notes in
`KNOWLEDGE/People/`.

## Contents
- `Guide - Export LinkedIn Profiles as PDF.md` — how to export profile PDFs
  from LinkedIn.
- `Skill - Process PDF Profiles to People Notes.md` — agent-executable
  extraction of a profile PDF into a person note.
- `Workflow - Process PDF Profiles to People Notes.md` — the human-led
  end-to-end process.

## Activation checklist
- [ ] Read the export guide and place profile PDFs in
      `ACTION CENTER/Agent Inbox/`.
- [ ] Run the skill on each PDF; verify the person note before moving the PDF
      out of the inbox.

## Boundary
Do not build a shadow staff directory. Where an organization-managed People
source exists, read it there and keep only your own relationship notes here.
