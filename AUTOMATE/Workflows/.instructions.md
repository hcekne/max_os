Repeatable step-by-step processes. Mix of human-led workflows and executable
automation recipes.

- Each workflow has: Goal, Inputs, Steps, Outputs, Quality Checklist.
- Agent-executable workflows are also listed in `SKILLS.md` at the vault root.
- For purely agent-executable capabilities, see also `AUTOMATE/Skills/`.
- Filename pattern: `Workflow - Name.md`.
- When creating a new workflow, use the template from `SYSTEM/Templates/TPL - Workflow.md`.
- Machine-readable Workflow Builder recipes live in `AUTOMATE/Workflows/Automations/`
  and carry `type: maxos-workflow` in frontmatter.
- Do not put run artifacts beside canonical workflow notes. Automation run
  artifacts belong under `AUTOMATE/Workflows/Automations/artifacts/`; final outputs
  should be delivered to `ACTION CENTER/My Inbox/` for owner review or to
  `ACTION CENTER/Outbox/` when externally ready.
- For new automation recipes, prefer document nodes and the document picker over
  hard-coded file paths.
