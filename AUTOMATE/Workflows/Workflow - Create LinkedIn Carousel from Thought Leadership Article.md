# Workflow - Create LinkedIn Carousel from Thought Leadership Article

## Goal
Turn one 2,500-3,200 word thought leadership article into a high-signal LinkedIn carousel that teaches something concrete, increases authority, and drives readers back to the full article.

## Inputs
- Source article (2,500-3,200 words; usually 7-8 chapters)
- Target audience + one primary pain/question
- One primary CTA (read full article / follow / book call)
- Carousel design template (cover, body, closing slide)
- Brand system (fonts, colors, visual style)

## Core principles
1. **Teach, don’t tease**: every slide must deliver standalone value.
2. **One idea per slide**: avoid mixed messages and cognitive overload.
3. **Narrative progression**: problem -> diagnosis -> framework -> action.
4. **Clarity beats cleverness**: 25-50 words max per slide.
5. **Authority through specificity**: use concrete examples, not generic claims.
6. **Article linkage**: carousel gives distilled value; article gives full depth.

## Slide architecture (default)
For a 2,500-3,200 word source article, use **12 slides** by default.

- Slide 1: Cover / hook (big promise + sharp tension)
- Slide 2: Why this matters now (stakes + business impact)
- Slide 3-9: Core insights (map major chapters to one key point each)
- Slide 10: Integrated framework/model (how pieces fit together)
- Slide 11: Practical action checklist (what to do next)
- Slide 12: Closing CTA (follow + full article + next action)

### When to adjust
- Use **10 slides** for lighter topics.
- Use **12 slides** as baseline.
- Use **14 slides** only when technical density is high.

## Format constraints
- Canvas size: 1080 x 1350 (portrait) or your proven template equivalent.
- Text per slide: 25-50 words max.
- Keep headline readable in-feed (large, high contrast).
- Export as PDF for LinkedIn carousel upload.

## Steps
1. **Extract carousel brief from article**
   - Write 1-sentence thesis.
   - Identify top 7-9 transferable insights.
   - Select one CTA.

2. **Choose carousel type (default = technical authority)**
   - Technical breakdown (best for thought leadership)
   - Listicle
   - Case/success story

3. **Build slide spine**
   - Draft 12 slide titles first (no body text).
   - Check that each title logically leads to the next.

4. **Write slide copy**
   - 25-50 words per slide.
   - Lead each slide with a strong assertion.
   - End selected slides with a bridge to the next one.

5. **Design pass using template**
   - Reuse consistent cover/body/closing layout.
   - Keep typography and color treatment consistent.
   - Use visual hierarchy: title > key line > supporting proof.

6. **Create post caption (separate from slides)**
   - Keep caption under ~500 characters.
   - Add context not already in slides.
   - Add one curiosity trigger (e.g., “Slide 8 is the inflection point”).
   - Mention relevant people only when materially relevant.

7. **Publish packaging**
   - File name should be clean and readable (public-facing).
   - Upload as LinkedIn Document (PDF).
   - Include full article link in first comment or caption.

8. **Publishing cadence**
   - Baseline: 2 carousels/week.
   - Start with Tue/Thu and test your audience time windows.
   - Avoid posting too many carousels back-to-back.

9. **Post-performance review (24-72h)**
   - Track impressions, dwell proxies, saves, comments, profile visits.
   - Note where readers drop off (if inferred from engagement patterns).
   - Log what worked: hook style, slide count, CTA style, topic angle.

## Outputs
- 1 LinkedIn carousel PDF (10-14 slides; default 12)
- 1 LinkedIn post caption
- 1 article link placement (caption/comment)
- 1 short performance note for iterative improvement

## Quality checklist
- [ ] Cover slide has clear tension and specific promise
- [ ] Each slide has exactly one core idea
- [ ] Slide copy stays within 25-50 words
- [ ] Narrative flow is coherent from slide 1 -> 12
- [ ] At least 1 practical framework/checklist is included
- [ ] Closing slide has explicit CTA
- [ ] Caption adds context (not duplicate text)
- [ ] Full article is linked

## Optional AI prompt block
Use this prompt when generating a first draft:

"Convert this 2,500-3,200 word thought leadership article into a 12-slide LinkedIn carousel.
Constraints: 25-50 words per slide, one idea per slide, technical-authority tone, practical value.
Output:
1) Slide-by-slide title + body copy
2) Suggested visual treatment per slide
3) 450-character LinkedIn caption with one curiosity trigger
4) Closing CTA that points to the full article."
