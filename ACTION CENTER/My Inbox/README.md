# My Inbox

Files, results, and updates for you to review.

## Rules
- Agents and workflows put review-ready results here.
- Review or act on each item, then move durable content to its canonical folder.
- Move completed transient items to the matching path below
  `SYSTEM/Cleaning/Archive/` or `SYSTEM/Cleaning/Rubbish Bin/`.
- Do not use My Inbox as long-term storage.
