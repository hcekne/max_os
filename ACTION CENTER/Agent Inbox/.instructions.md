# Agent Inbox Instructions

Raw captures land here. Process daily.

- Follow the Agent Inbox Processing Algorithm in `SYSTEM/LLM Operating Manual.md`.
- Route each item to: people, organization, client, project, interaction, content, or todo.
- Create missing notes from templates in `SYSTEM/Templates/`.
- Extract explicit tasks to `PLAN/Todos/` or today's daily note in `PLAN/Daily/`.
- Add cross-links between all touched notes.
- After routing, move every processed item out of the active root of `ACTION CENTER/Agent Inbox/`.
- Move low-retention processed inputs to the matching path below
  `SYSTEM/Cleaning/Rubbish Bin/ACTION CENTER/Agent Inbox/`; use Archive for
  historically useful source material.
- Do not leave already-routed article drafts, transcripts, or processed captures beside active inbox items.
- When scanning inbox folders, use direct directory listings as the source of truth before relying on globbed search.

- Process LinkedIn profile PDFs directly with
  `AUTOMATE/Skills/Skill - Process PDF Profiles to People Notes.md`; do not create a
  persistent extraction or profile-staging folder. After a successful person-note
  write, move the source PDF out of Agent Inbox immediately. Leave only failed or
  ambiguous PDFs visible for follow-up.
