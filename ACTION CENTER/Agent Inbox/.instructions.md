# Agent Inbox Instructions

Raw captures land here for Max OS to process.

Processing algorithm:

1. Scan `ACTION CENTER/Agent Inbox/` newest-to-oldest, using direct
   directory listings before relying on globbed search.
2. Route each item to one destination: people, organization, client,
   project, interaction, content, or todo.
3. Create missing notes from templates in `SYSTEM/Templates/`.
4. Merge factual updates into canonical notes.
5. Extract explicit tasks into `PLAN/Todos/` or today's daily note in
   `PLAN/Daily/`.
6. Add cross-links between all touched notes.
7. Move every processed item out of the active root: low-retention inputs to
   the matching path below `SYSTEM/Cleaning/Rubbish Bin/ACTION CENTER/Agent
   Inbox/`, historically useful source material to Archive.

Rules:

- Do not leave already-routed drafts, transcripts, or processed captures
  beside active inbox items.
- Do not recreate persistent staging or extraction folders inside the inbox.
- The optional LinkedIn profile-import module
  (`AUTOMATE/Modules/LinkedIn Profile Import/`) processes profile PDFs when
  enabled; move each source PDF out of the inbox after a successful person
  note.
